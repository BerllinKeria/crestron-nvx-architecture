# Crestron NVX Architecture & AV over IP

## 项目简介

本文以Crestron DM NVX 系统为例，介绍AV over IP的基本原理、主要设备、系统架构以及音视频数据传输机制。

## 主要内容
- 传统 HDMI 矩阵与 AV over IP
- NVX Encoder、Decoder、CP3N、DSP 与网络交换机
- 一对一、一对多和多对多的 NVX 部署架构
- 组播、IGMP、IGMP Snooping 与IGMP Querier
- NVX源端解嵌与接收端解嵌
